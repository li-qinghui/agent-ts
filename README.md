# Agent 技术调研与应用项目

## 项目定位

本项目专注于 **Agent 技术的调研与应用规划**，不涉及实际开发工作。主要目标是：

1. **跟踪最新动态** - 关注各大厂和开源社区的 Agent 最新进展
2. **收集有价值的信息** - 开源项目、技术方案、优质资讯
3. **应用落地规划** - 探索如何将 Agent 思想应用到实际工作中
4. **公司内推广** - 规划 Agent 技术在组织内部的应用

## 核心原则

- **调研驱动** - 以信息收集和分析为主
- **应用导向** - 所有调研最终指向实际应用
- **双向链接** - 使用 Obsidian 语法建立知识关联
- **渐进积累** - 目录结构支持逐步扩展

## 主要目录说明

### 1. research/

**调研资料库**，系统性地收集和整理 Agent 相关的技术资料：

- `tech-trends/` - 技术趋势分析（大厂动态、新技术方向）
- `open-source/` - 开源项目追踪（项目评测、使用分析）
- `industry-news/` - 行业资讯（最新资讯、观点文章）

### 2. applications/

**应用落地规划**，记录如何将调研成果应用到实际工作中：

- `internal/` - 公司内部应用场景和方案
- `proposals/` - 应用提案和规划文档

### 3. insights/

**个人洞察**，基于调研形成的思考和总结：

- `thoughts/` - 思考与总结
- `patterns/` - 发现的模式与规律

### 4. reports/

**定期报告**，周报/月报形式的阶段性总结

### 5. archive/

**历史归档**，归档已完成的调研和过期的文档
