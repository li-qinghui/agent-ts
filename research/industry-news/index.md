# 行业资讯收集

本目录用于收集和整理 Agent 领域的行业资讯，包括最新资讯、观点文章、技术博客等。

## 目录结构

```
industry-news/
├── index.md               # 本索引文件
├── 2026-05.md             # 2026年5月资讯汇总
├── 2026-04.md             # 2026年4月资讯汇总
├── important-articles.md  # 重要文章收藏
├── weekly-summary.md      # 每周资讯摘要
└── resources.md           # 优质资源列表
```

## 资讯整理规范

每条资讯应记录以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 日期 | 发布时间 | 2026-05-05 |
| 来源 | 发布平台 | 微信公众号 |
| 标题 | 文章标题 | Agent 技术最新进展 |
| 链接 | 原文链接 | https://... |
| 标签 | 相关主题 | #技术趋势 #开源 |
| 摘要 | 核心要点 | 200字以内的总结 |
| 价值 | 重要程度 | 高/中/低 |
| 相关 | 相关文档 | 关联的其他文档 |
