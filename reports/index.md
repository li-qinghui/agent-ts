# 定期报告

本目录用于存放周报、月报等定期报告形式的阶段性总结。

## 报告结构

```
reports/
├── index.md               # 本索引文件
├── weekly/
│   ├── 2026-05-week1.md   # 2026年第1周
│   ├── 2026-05-week2.md   # 2026年第2周
│   └── ...
└── monthly/
    ├── 2026-05.md         # 2026年5月
    └── ...
```

## 报告类型

### 周报 (weekly/)

每周调研工作的简要总结，包括：

- 本周完成的主要调研
- 发现的重要信息
- 下周计划

### 月报 (monthly/)

每月调研工作的详细总结，包括：

- 本月调研概览
- 主要发现和洞察
- 应用落地进展
- 下月计划

## 周报模板

```markdown
# 第X周调研报告（YYYY-MM-DD）

## 本周完成
- [ ] 调研项1
- [ ] 调研项2

## 主要发现
### 发现1
发现内容...

### 发现2
发现内容...

## 重要资讯
| 日期 | 来源 | 标题 | 摘要 |
|------|------|------|------|

## 下周计划
- [ ] 计划1
- [ ] 计划2

## 备注
其他需要说明的事项...
```

```markdown

## 下月计划

- 本月收集的文档列表
- 本月形成的文档列表
```
