# 应用落地规划

本目录记录如何将调研成果应用到实际工作中，包括公司内部应用场景、应用提案等。

## 目录结构

```
applications/
├── index.md               # 本索引文件
├── internal/              # 公司内部应用
│   ├── index.md
│   ├── workflow-automation.md
│   ├── document-processing.md
│   ├── customer-service.md
│   └── knowledge-management.md
└── proposals/            # 应用提案
    ├── index.md
    ├── pilot-project.md   # 试点项目提案
    └── implementation-plan.md
```

- [[internal/customer-service|智能客服]] - 客服场景 Agent 应用
