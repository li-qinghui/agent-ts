# 历史归档

本目录用于归档已完成或过期的文档，保持项目结构的整洁。

## 归档分类

### 1. 已完成的调研

归档已完成调研的详细资料。

### 2. 过期的提案

归档过期或被搁置的应用提案。

### 3. 历史版本

文档的历史版本存档。

### 4. 临时文件

临时存放的文件，等待整理或删除。

## 归档规范

1. 归档前检查是否有其他文档引用
2. 更新相关链接或移除无效链接
3. 记录归档原因和日期
4. 定期清理不再需要的归档文档
